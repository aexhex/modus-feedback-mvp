# Сценарий защиты на 5 минут

Главная мысль, которую должно унести жюри: **в «Голосе сотрудника» ни одно обращение не теряется — у каждого есть ответственный, срок и результат, который автор видит сам.**

Показываем четыре сильных момента. Всё остальное — в запасе, на вопросы.

## Подготовка (за 10 минут до выхода)

1. `npm start`, браузер на http://localhost:3000, масштаб страницы 100–110 %, светлая тема.
2. Войти администратором → «Настройки» → «Сбросить демо-данные». Это вернёт исходные 20 обращений и сроки «как сегодня».
3. Открыть две вкладки: в первой — экран входа, во второй — `http://localhost:3000/#/client` (форма для клиентов, если спросят).
4. Телефон (по желанию): в той же сети Wi-Fi открыть `http://<IP компьютера>:3000`, войти «Сотрудником офиса».
5. Запасной план, если что-то не запустится: [скриншоты](screenshots/), а также локальные видео с озвучкой и слайды (в репозиторий не входят: видео собирается командами `npm run voice`, `npm run video`, `npm run video:voice`).

## Сценарий

| Время | Кто | Что делаем | Что говорим |
|---|---|---|---|
| 0:00–0:30 | Экран входа | Показать 4 роли | «Сейчас идеи и жалобы теряются в чатах и разговорах: автор не знает, что с его предложением, руководитель не видит повторяющихся проблем. Мы сделали один канал, где у каждого обращения есть хозяин, срок и итог». |
| 0:30–1:45 | **Сотрудник офиса** (карточка «Сотрудник») | «+ Новое обращение» → «Проблема» → категория «Хранение документов» → в теме набрать «Не найти актуальную инструкцию в общих папках». Справа появится похожее A-019 — показать кнопку «У меня тоже». Отправить. | **Момент 1 — подача за минуту.** «Система сама находит похожее: вместо дубля можно отметить "у меня тоже". После отправки у обращения сразу номер, ответственный по правилу категории и срок ответа в рабочих днях». |
| 1:45–2:45 | **Руководитель** (карточка «Руководитель» — вход сразу) | Главная: красная плитка «Просрочено по SLA» → щёлкнуть по ней → открыть A-007 → в истории запись «Нарушен SLA» → назад на главную, показать график. | **Момент 2 — ничего не теряется.** «Просрочки видны сразу, руководитель и ответственный получают уведомление автоматически и напоминание каждые два рабочих дня. Обращение не может молча зависнуть». |
| 2:45–3:45 | **Сотрудник офиса** | «Мои обращения» → A-017 → «Мотивированный отказ» → кнопка «Нет, не решён». Затем «Итоги внедрения»: отчёт о внедрении и «автор месяца». | **Момент 3 — автор всегда получает ответ.** «Закрыть обращение без результата нельзя — даже отказ с причиной. Автор оценивает, решён ли вопрос. А реализованные идеи видны всем: это главный мотив предлагать дальше». |
| 3:45–4:30 | **Сотрудник офиса** → «Идеи коллег» | «Сначала популярные» → открыть A-014 → показать голоса. | **Момент 4 — идеи обсуждает вся компания.** «Автор может открыть идею коллегам: её комментируют и голосуют, у каждого 5 голосов. Руководитель видит, что важно людям, а не только тому, кто громче». |
| 4:30–5:00 | — | Вернуться на экран входа. | «Это работающий MVP: 168 серверных тестов, 63 теста интерфейса, проверка доступности. Интеграции с Битрикс24 и 1С УТ работают на демо-портале настоящими HTTP-запросами: для подключения к порталу компании достаточно адреса вебхука. Дальше — пилот на двух отделах по плану из концепции и вход через Битрикс24». |

## Если спросят — что показать

| Вопрос | Что показать (роль) |
|---|---|
| Как это видит ответственный? | **Ответственный за номенклатуру** → «Канбан» → перетащить карточку; карточка A-003 → шаблон ответа, внутренняя заметка, «Ещё действия». |
| Что с анонимностью? | **Сотрудник** → новое обращение → «Подать анонимно». Имя и подразделение скрыты от всех, включая руководителей и журнал Битрикс24. Опросы показывают результаты только после закрытия и при трёх и более ответивших. |
| А если ответственный в отпуске? | **Администратор** → «Настройки» → снять «на месте»: новые обращения уйдут резервному. При отключении пользователя его открытые обращения переходят следующему по правилу. |
| Как руководителю получить отчёт? | **Руководитель** → «Сводка недели» (готовый текст для рассылки) или «Отчёт за период» → «Печать / PDF»; «Экспорт в Excel» в реестре. |
| Что происходит, когда задачу в Битрикс24 закрыли? | **Ответственный за договоры** → A-009 → «Ещё действия» → «Создать задачу в Битрикс24», затем «Завершить задачу на демо-портале». Система раз в 5 минут проверяет статусы задач: в карточке «Статус в Битрикс24: Завершена», в истории — «подтвердите результат и зафиксируйте итог», ответственному приходит уведомление. Итог фиксирует человек. |
| Как проверить полезность? | План пилота в [концепции](CONCEPT.md): 2 отдела, 6 недель, 10 показателей с порогами; первые шесть уже заведены целями в «Настройках» и видны на «Показателях» как план/факт. |
| Как подключить к вашему Битрикс24? | Портал облачный, поэтому код дорабатывать не нужно: администратор портала создаёт входящий вебхук, его адрес задаётся в переменной `B24_WEBHOOK_URL` — уведомления и задачи начинают уходить на портал. Нужен исходящий доступ сервера в интернет. Для входа через Битрикс24 и обратной связи по задачам нужен адрес системы по HTTPS. |
| Где интеграция с Битрикс24 и 1С? | **Администратор** → «Настройки» → «Интеграции»: «Загрузить оргструктуру» → видно, кто добавится, переведётся и будет отключён → «Применить изменения». Ниже «Журнал отправки в Битрикс24» — статусы «Отправлено» с номером от портала. «Загрузить контрагентов» — справочник клиентов из 1С; затем **Сотрудник** выбирает клиента в новом обращении. Там же адрес и токен выгрузки для 1С. Все вызовы идут на встроенный демо-портал; для настоящего — переменные `B24_WEBHOOK_URL`, `ONEC_ODATA_URL`. |
| Как увидеть повторяющиеся проблемы? | **Руководитель** → «Показатели» → «Карта повторяющихся проблем»: «Каталог и данные» затрагивает 4 отдела. Рядом — цели показателей: что в цели, что нет. |
| Где хранятся принятые решения? | Любая роль → «База решений»: что решили и почему отказали, с поиском. При подаче нового обращения похожее рассмотренное сразу показывает «Уже решено». |
| А клиенты? | Вкладка `/#/client`: форма без входа; **Руководитель** → «Отзывы клиентов» → NPS. |
| А на казахском или английском? | Переключатель **RU · KZ · EN** вверху справа (и на экране входа): интерфейс, справочники и сообщения переводятся, текст обращений остаётся на языке автора. |
| Можно с телефона? | Телефон: «+ Новое обращение» → «📷 Сделать фото». Фото сжимается прямо в браузере. |
| Как проверено качество? | `npm test` и `npm run test:e2e`; автоматическая проверка доступности по WCAG 2.1 AA; три независимые проверки кода и безопасности, замечания исправлены. |

## Чего не делать на защите

- Не открывать все разделы подряд: четыре момента выше уже занимают 5 минут.
- Не показывать «Настройки» без вопроса — это интересно администраторам, а не жюри.
- Не создавать обращения с реальными данными компании: все данные в демо синтетические.
